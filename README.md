# mylana — downloads

Website and release downloads for [mylana](https://mylana.xyz), a personal
finance advisor that runs entirely on your machine.

- **Download:** the [latest release](https://github.com/roberjacobo/mylana-releases/releases/latest)
- **Manual:** https://mylana.xyz/HANDBOOK.html

The app is free to download and needs a one-time activation key issued by the
developer. The source code lives in a private repository; installers are
published here by its release workflow.
